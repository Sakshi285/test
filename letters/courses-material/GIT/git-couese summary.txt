Branch

    git branch FeatureBranch //create a new branch
    echo master branch > newFileMaster.txt //create a new file in master branch
    git add .
    git commit -m "Master branch commit"
    git log
    git checkout <branch name> //enter in perticular directory - switches to differnt branch
    echo feature branch -> newFileFeatureBranch.txt

Checking status and inspecting commits
    git show <copy hashkey and paste> //gives extensive commit info
    git show --name-only <hash> //gives shorthand commit info
    git reflog // gives info about all commits on all branches

Push and Pull
    git push <branch> // add code on git
    git pull <branch> // retrive the code which is commited

Undo and redo changes
    git log
    git revert <hash> // creates  a new commit to undo changes
    :q
    git reset <hash> //commit will clean but  changes are as it is
    git reset --soft <hash> //removes commits from history keeps changes
    git reset --hard <hash> //removes commits from history removes changes

Merging branches
     git merge FeatureBranch
     git log

pull requests and code reviews
